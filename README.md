# Icon button

Two tiles: **Icon button** runs a script; **Switch button** toggles a light, switch, input_boolean or fan and shows whether it is on.

A tile that is only an icon. Tap it and it runs a script of Home Assistant: a plus and a minus for
a thermostat, a play button, a lock.

## Set up

1. Add the plugin to a screen in Tessera. The screen builds once.
2. In Layout, place the **Icon button** tile from the library's Plugins group.
3. In the inspector, choose the script it runs, then the icon and its colour. Optionally write a few words under the icon.

## Good to know

- Works with `script.*` only.
- The editor preview shows the tile's name; the icon is drawn on the screen itself.
